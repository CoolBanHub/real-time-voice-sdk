演示说明（README）

如何开始

  • 首次打开页面请允许麦克风权限。
  • 说出唤醒词 小金小金，状态从“休眠中”变为“已唤醒”。
  • 正常对话会在左侧显示“对话记录”；触发指令会在右侧显示“自定义指令”卡片（intent / 参数 / 耗时）。

当前支持的自定义指令（可直接口述测试）

  • 音乐控制（command.music）：播放/暂停/继续/停止/上一首/下一首/搜索
    播放周杰伦的歌 暂停 继续播放 下一首 上一首 停止音乐 搜索说唱音乐

可选：如何“自定义”规则（给调试/验证用）

  • 规则文件目录：server/config/rules/music.json。
  • 你可以修改关键词、正则、优先级等；保存后重启服务即可生效。
提示：本 Demo 重点演示“识别与回显”。音乐动作默认不接真实业务。
